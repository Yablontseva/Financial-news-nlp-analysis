## Цель работы

Повышение качества автоматической обработки и анализа финансовых новостей с использованием методов обработки естественного языка.

## Основные задачи

- анализ финансовых текстовых данных;
- классификация тональности финансовых новостей;
- применение TF-IDF и классических алгоритмов машинного обучения;
- использование трансформерной модели FinBERT;
- прогнозирование направления изменения фондового индекса;
- реализация подхода data fusion;
- оценка качества моделей и сравнительный анализ результатов.

## Используемые датасеты

- Financial PhraseBank Dataset: https://huggingface.co/datasets/takala/financial_phrasebank
- Financial Sentiment Analysis Dataset: https://www.kaggle.com/datasets/sbhatti/financial-sentiment-analysis
  
### Financial PhraseBank
Датасет финансовых новостей с экспертной разметкой тональности:
- positive
- neutral
- negative

### Daily News for Stock Market Prediction
Датасет новостных заголовков, связанных с изменением индекса Dow Jones Industrial Average (DJIA).

## Реализованные модели

### Анализ тональности
- Logistic Regression
- Linear SVM
- Naive Bayes
- Random Forest
- FinBERT

### Прогнозирование фондового индекса
- TF-IDF + Logistic Regression
- TF-IDF + Data Fusion
- TF-IDF + FinBERT Data Fusion
